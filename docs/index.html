PDF 转图片工具

一款 Windows 桌面应用，支持将 PDF 批量转换为 PNG、JPEG、BMP、TIFF、WEBP、GIF 等常见图片格式。

免费下载，无需登录，适用于 Windows 10 / 11 及更高版本（64 位）

功能特性

批量转换 一次添加多个 PDF，支持拖拽上传
多种格式 PNG、JPEG、BMP、TIFF、WEBP、GIF
可调分辨率 96 / 150 / 200 / 300 / 600 DPI
页码范围 全部页或指定页，如 1-5、1,3,5
中英文界面 右上角可切换语言
现代 Windows 支持 Windows 10、11 及当前主流 64 位系统
安装即用 Inno Setup 安装向导，一键完成部署
